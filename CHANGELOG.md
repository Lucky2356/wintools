# Изменения

## 0.6.0-rc.2

- Исправлен переход по карточкам категорий: обработчик выбора больше не читает старое значение фильтра.
- Смена категории сбрасывает ограничение предыдущей подборки, поэтому разделы не становятся пустыми из-за скрытого фильтра.
- При ошибке сохранения плана добавление, удаление и перестановка отменяются; сообщение об ошибке больше не заменяется сообщением об успехе.
- Исправлен статус готового обновления после повторного включения автоустановки; убраны устаревшие советы о токене из ошибок публичного обновления.
- UI-тест активирует настоящие кнопки всех категорий и подгрупп через Windows UI Automation. Добавлены проверки заблокированного файла настроек и переходов из подборок.

## 0.6.0-rc.1

- План изменений с сохранением списка, перестановкой действий, общим предпросмотром, последовательным выполнением и остановкой при ошибке или по запросу пользователя.
- Каталог открывается разделами и подгруппами вместо длинного списка; сохранены поиск, избранное и доступ ко всем действиям.
- Автообновление публичного репозитория без токена: проверка при запуске и каждые 6 часов, загрузка с SHA-256 и установка при закрытии без повторного запуска.
- Все настройки обновления перенесены в настройки приложения; автоматическую проверку и установку можно отключить независимо.
- Переписаны все 201 описание: понятный результат, последствия и условия вместо ключей реестра и необоснованных обещаний ускорения.
- Новые подборки для уменьшения рекламы, настройки Проводника и отключения фоновой записи игр; изменения остаются под контролем пользователя.
- Нейтральная палитра с синим акцентом, более крупный текст с отрисовкой по пиксельной сетке, векторная иконка в EXE и заголовке окна.
- Выбранный твик остаётся видимым после смены фильтра. Исправлены отступы навигации в компактном окне.
- Назначение WintoolsData объясняется в настройках. Журнал и резервные копии сохраняются при обновлении.
- Проверки публичного скачивания без секретов в CI, автозагрузки после завершения операции, отключения автоустановки и замены EXE без перезапуска.

## 0.5.0-rc.1

- Полный редизайн на встроенном WPF: единые темы для кнопок, полей, списков, переключателей и прокрутки.
- Исправлены обновления закрытого репозитория: авторизация проверки и скачивания EXE через GitHub API.
- Токен GitHub хранится зашифрованным Windows DPAPI; добавлены понятные ошибки доступа и прогресс загрузки.
- Неполный новый релиз больше не выдаётся за отсутствие обновлений.
- Ошибка чтения вывода не снимает блокировку до завершения процесса; чтение больших логов ограничено.
- История сгруппирована по запускам, повторный откат отменённых записей отключён.
- Операции блокируются, если повышение прав выполнено под другим пользователем Windows.
- CI проверяет настоящий авторизованный запрос релизов и скачивание EXE, ошибки HTTP и шифрование доступа.

## 0.4.0-rc.2

- Светлая, тёмная и системная темы с сохранением выбора.
- Боковая навигация, отдельная карточка действия и сворачиваемый вывод операций.
- Избранное сохраняет выбранное действие; недоступный журнал не закрывает приложение.
- Обработка повреждённых настроек и обновление EXE с русским именем.
- Проверка переключения тем, компактного окна и снимки интерфейса в CI; ошибки UI-теста возвращают ненулевой код.

## 0.4.0-rc.1

- Графический portable-интерфейс: каталог, поиск, избранное, предпросмотр и история отката.
- Один EXE со встроенным движком; установка среды и NuGet-зависимости не нужны.
- Проверка GitHub Releases при запуске, каналы stable/RC и установка обновления с проверкой SHA-256.
- Атомарная замена EXE с сохранением предыдущей версии и portable-данных.
- Сборка, запуск UI и проверки обновления на GitHub Windows 2022/2025.

## 0.3.0-rc.1

- Диагностика ресурсов и автозапуска без изменения системы, JSON-отчёт и пункт Q в меню.
- Консервативные значения по умолчанию, явный выбор системных изменений и проверка ID.
- Очистка с контролем ссылок, ошибок, исходного состояния служб и настроек Disk Cleanup.
- Сборка ZIP и SHA-256 только после успешных проверок обеих платформ GitHub.


- Откат реестра сохраняет посторонние данные в созданных ключах.
- Исходные значения читаются через Registry API; неподдерживаемые данные блокируют изменение.
- GitHub CI проверяет реальные временные объекты Windows Server 2022 и 2025.

## 0.2.0

Код соответствует 0.2.0-rc.1; новых функциональных изменений нет.
Выпуск оформлен без дополнительного тестирования. Полный цикл применения,
проверки и отката на Windows-ВМ с перезагрузкой не выполнялся.
Ограничения отката, перечисленные ниже, сохраняются.

## 0.2.0-rc.1

- Ошибки записи журнала останавливают изменения; статусы обновляются атомарно.
- Повторные изменения и разные SID сохраняют отдельные исходные состояния.
- Выборочный откат учитывает более новые записи, а ошибка восстановления
  останавливает дальнейший обход истории.
- Ошибки системных команд и неполный откат AppX больше не отмечаются успехом.
- Ошибки записи метаданных и экспорта реестра останавливают глубокое удаление AppX.
- `verify` проверяет реестр, службы, задачи, AppX, гибернацию, TCP, NTFS и
  тайм-ауты питания; отдельно сообщает об ошибках чтения и неподдерживаемых записях.
- Добавлены проверки критичных отказов без изменения настроек рабочей системы.

Это кандидат на выпуск. Полный цикл на Windows-ВМ со снимком и проверкой после
перезагрузки пока не выполнен. Удаление Edge и provisioned-копии AppX по-прежнему
не имеет полного локального отката; очистка диска необратима.
