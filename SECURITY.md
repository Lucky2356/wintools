# Безопасность

`wintweaks` выполняет системные команды с правами администратора. Загружайте
релизы только из доверенного источника, не запускайте проект из каталога, куда
могут записывать другие пользователи, и сначала используйте `/dry` на тестовой
машине.

## Сообщить о проблеме

Не публикуйте уязвимость в issue до исправления. Отправьте владельцу репозитория
приватное security advisory с версией Windows, командой воспроизведения и
минимальным примером. Не прикладывайте журналы без проверки: они могут содержать
имя компьютера, SID, пути и сведения об установленных приложениях.

## Границы гарантий

Файлы `state/`, `backups/` и `logs/` содержат локальное состояние и не должны
синхронизироваться между компьютерами. Аварийно оставшийся `state/run.lock`
можно удалить только после проверки, что другой экземпляр `wintweaks` не работает.
